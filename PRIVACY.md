# AutoFill Privacy Policy

**Last updated:** September 20, 2026

AutoFill is a local-first Chrome extension that helps users fill supported online forms using information they provide.

## Information stored by AutoFill

AutoFill may store the following information locally in the user’s browser:

- Personally identifiable information such as name, email address, phone number, GitHub, LinkedIn, portfolio, Discord, and custom profile fields.
- User-created Q&A answers and unfinished Q&A drafts.
- Resume, cover-letter, and profile-photo files selected by the user.
- Extension settings, such as whether the floating AutoFill button is enabled.

This information is stored using Chrome’s local extension storage. AutoFill does not operate a backend server or central database for this information.

## How AutoFill uses information

AutoFill uses stored information only to provide its form-assistance features:

- Detecting supported fields on webpages.
- Highlighting fields during a user-requested scan.
- Filling fields after the user clicks AutoFill.
- Suggesting matching answers from the local Q&A bank.
- Attaching a selected file to a supported upload field after the user clicks AutoFill.

The current public version does not use AI services, analytics, advertising, or behavioral tracking.

## Sharing and transmission

AutoFill does not sell, rent, or transmit profile information, Q&A answers, webpage form data, or selected files to the developer or third-party services.

If a user voluntarily includes personal information in a GitHub issue or pull request, that information is handled by GitHub under GitHub’s own privacy practices. Users should not include passwords, API keys, resumes, contact details, or other sensitive information in public issues or pull requests.

## Webpage access

AutoFill requests access to webpages because application forms can be hosted on many different websites. It uses that access to identify supported form controls, display scan highlights, fill user-provided values, and attach user-selected files when the user initiates an action.

AutoFill does not collect browsing history, monitor keystrokes, record clicks, or track the websites a user visits for analytics.

## Data deletion

Users can remove individual profile fields, answers, and files from inside AutoFill. Uninstalling AutoFill removes its locally stored extension data according to Chrome’s extension-storage behavior.

## Changes to this policy

This policy may be updated when AutoFill’s data practices or features change. The latest version will be published in this repository.

## Contact and support

For support, compatibility reports, and feature suggestions, please use the [AutoFill GitHub Issues](https://github.com/vking-ly/AutoFill/issues) page. Contributions can be submitted through [GitHub pull requests](https://github.com/vking-ly/AutoFill/pulls).
